# Adam's Source

An [AltStore Classic](https://altstore.io) source with my apps.

To add it, open AltStore, go to **Sources**, tap **+**, and enter:

```
https://raw.githubusercontent.com/adamgrushan/altstore-source/main/source.json
```

## Apps

- **Museum Companion**: point your iPhone at an artwork and hear about it. Requires iOS 26 or later.

## Layout

- `source.json`: the source AltStore reads ([format](https://faq.altstore.io/developers/make-a-source)).
- `museum-companion/`: images for the app's listing.
- The IPAs are attached to this repo's [releases](https://github.com/adamgrushan/altstore-source/releases), since they're over GitHub's 100 MB file limit.
